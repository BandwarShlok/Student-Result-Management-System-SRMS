Student Result Management System (SRMS)
Description

Student Result Management System (SRMS) is a web-based application developed to manage and display student academic results digitally. It allows administrators to add, update, and manage student and result records, while students can securely view their results online. The system helps reduce paperwork, saves time, and improves accuracy in result management.

Features

Admin registration and login

Add, update, and delete student details

Manage and publish student results

Students can view results online

Secure backend APIs

Simple and user-friendly interface

Technologies Used

Frontend: HTML, CSS, JavaScript

Backend: Node.js, Express.js

Database: MongoDB

Tools: VS Code, Git, GitHub

Project Structure

Backend
Frontend

How to Run the Project

Open the project folder

Go to the Backend directory

Run npm install

Start the server using node server.js

Open the frontend HTML files in a browser
